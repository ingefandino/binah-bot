## Cómo trabajamos (procesos)
- Producto nuevo (6-16 semanas hasta MVP): Discovery, Diseño (Figma + arquitectura), MVP/Build (sprints semanales, GitHub desde día 1), Lanzamiento (DevOps, dominio, observabilidad), Run & Iteración.
- Modernización / Migración: upgrade de versión 2-8 semanas; cambio de stack 3-18 meses; re-arquitectura 6-24 meses. Pasos: auditoría, mapeo de dominio, estrategia, ejecución módulo a módulo, validación paralela, cutover gradual (canary), retiro del legacy.
- Mantenimiento y evolución: contrato mensual, mínimo 3 meses. Onboarding, estabilización, roadmap conjunto, sprints quincenales, soporte on-call opcional con SLA.
- Auditoría técnica (1-4 semanas): code review, arquitectura, seguridad (OWASP Top 10), datos y deuda técnica, reporte ejecutivo y técnico, plan de remediación opcional.
- Rol como servicio: mínimo 3 meses, el rol se integra al equipo (standup, planning, retro), revisión mensual.
